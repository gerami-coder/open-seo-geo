Independent SEO plugin with content-derived keyword/title/description automation,
published-page SEO health scans and safe fixes, plain-language AI search readiness, structured data templates, local business locations,
news/video sitemaps, podcast RSS, internal-link tools, metadata CSV workflows,
public-page comparison and direct Google Search Console integration/history.

Automation is enabled by default. Installation/upgrading automatically queues
existing posts/pages in WP-Cron batches; new saves fill only blank SEO fields.
Authored values, content and per-page exclusions are preserved.

GEO Website Info provides a central overview, key facts and public contact details
with live preview and selected-page display. Enable it only for the published
pages you choose. Central updates propagate without replacing page content or
SEO fields; unselect pages or disable display to remove the section.

No plugin subscription or credit system is required for the local additions.
Optional local-model writing requires Ollama and an installed model on the
WordPress server. Google authorization requires the site's own OAuth project.

See INSTALL.md for setup, feature boundaries and upgrade instructions.
See NOTICE.txt, CHANGES.md, UI-BRANDING-CHANGES.txt and COPYING for provenance,
modifications and licensing. UPSTREAM-README.txt preserves the original readme.

Use on staging before production. Do not run alongside another SEO engine.
No error-free operation, indexing, ranking, rich-result or AI-citation guarantee
is made. The code is provided under the included license without warranty.
